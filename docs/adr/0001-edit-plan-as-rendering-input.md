# Render from an independently editable edit plan

OBS marker CSV records decisions made during capture, but those decisions may need correction afterward. The converter produces an edit plan from the CSV, including each transition's resolved duration, and the MLT renderer consumes that plan independently, so corrections to the plan do not require modifying the capture log or depend on later configuration changes. Conversion can run without the source media and refuses to overwrite an existing plan unless replacement is explicitly requested. Plans refer to the source recording portably where possible and permit explicit source-path correction after a move. Rendering checks the actual source recording's properties and verifies that kept plan intervals fit within its duration; a discarded tail may extend beyond the recording because it contributes no footage to the output. This separates capture from rendering and gives the plan a stable role as the input to future renderers.
